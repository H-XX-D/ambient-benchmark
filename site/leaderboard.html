Submission contents

What is required for a published row

A submission includes a hashed manifest, transcript, verdicts, summary, declared track, source commit, and uncertainty interval. Validation rejects missing pairs, reader drift, mock output, judge errors, unsafe paths, metric disagreement, and hash mismatches.

Submission specification

Before you enter

What a leaderboard run involves

AMBIENT is a controlled, evidence-producing evaluation—not a single prompt or a model popularity contest. Entrants should expect four memory conditions, independent judging, trace inspection, and a publishable artifact bundle.

01 / Connect

Expose an observable memory query

The adapter must return the exact external context served for each question. If the harness cannot observe a non-empty store response, the answer cannot earn memory credit.

02 / Execute

Run every question four ways

T1 disables memory, T2 enables reference capture, T3 combines both paths, and T4 isolates the selected memory. A complete hosted run is 400 unique questions and 1,600 judged tier rows.

03 / Prove

Keep the full evidence trail

Expect manifests, raw transcripts, served context, verdicts, summaries, fingerprints, and SHA-256 checks. Missing pairs, drift, mock output, or any reader, adapter, or judge error blocks publication.

04 / Compare

Match the right board

Hosted results are automatic and unreviewed. Architecture claims require fixed controls, balanced order, at least three repeats, and 30 unique questions per ability. Native systems are reported separately.

Inside the test

Inside the 400-question hosted test

BEAM-small contributes 40 unique questions in each of ten memory families. The harness asks every question under T1–T4, producing 1,600 judged rows. Each card explains the expected behavior and the failure pattern the family is designed to expose.

01

Knowledge update

What it tests
Retrieves the newest valid value after a fact changes across sessions.
Why it’s difficult
Both old and new statements remain relevant; retrieval may serve the obsolete one or the reader may blend them together.
02

Contradiction resolution

What it tests
Recognizes incompatible statements and responds with uncertainty or clarification instead of choosing arbitrarily.
Why it’s difficult
Conflicts can be distant, paraphrased, and individually plausible; simple last-write-wins behavior can hide the disagreement.
03

Multi-session reasoning

What it tests
Combines evidence split across separate, distant conversations.
Why it’s difficult
No single retrieved passage is sufficient; the system must recover several supporting facts without letting distractors take over.
04

Temporal reasoning

What it tests
Answers time-relative and “as of” questions from timestamped events.
Why it’s difficult
Current truth and historical truth can differ, so event order, reference date, and temporal language must all be interpreted correctly.
05

Event ordering

What it tests
Reconstructs the correct sequence of events from the remembered record.
Why it’s difficult
Remembering the events is not enough; one omission, tie, or misplaced event can distort the entire chronology.
06

Information extraction

What it tests
Recovers a specific detail that was explicitly stated in the conversation history.
Why it’s difficult
The answer may be a small needle among many plausible near-matches and unrelated sessions.
07

Preference following

What it tests
Remembers an earlier user preference and applies it to a later response.
Why it’s difficult
The preference may be implicit or revised, and success requires changing the answer—not merely retrieving the preference verbatim.
08

Instruction following

What it tests
Applies a standing instruction that was issued earlier in the history.
Why it’s difficult
The instruction can be far from the question or revised later; the latest valid instruction must still control the response.
09

Summarization

What it tests
Condenses a long span while preserving the important facts and changes.
Why it’s difficult
Compression can erase chronology, qualifiers, contradictions, or the difference between old and current state.
10

Abstention

What it tests
Declines when the remembered record does not contain enough information to answer.
Why it’s difficult
There is no supporting passage to retrieve, while a fluent, plausible guess is still scored as gullible.
