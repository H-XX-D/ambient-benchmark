Privacy Policy

AMBIENT is an open-source benchmark. Its Vercel website has no accounts, advertising, first-party analytics, or API-key fields. The optional runner uses Hugging Face sign-in and Inference Providers.

Information we collect

The AMBIENT maintainers do not set first-party cookies or create visitor profiles on the Vercel website. The Vercel deployment links to the hosted runner but does not receive, proxy, or store a Hugging Face OAuth token.

Infrastructure and third parties

The primary site is hosted by Vercel and the optional runner is hosted by Hugging Face Spaces. Like most hosting providers, they may process request information such as IP addresses, device or browser details, timestamps, and requested URLs for delivery, reliability, abuse prevention, and security. That processing is governed by Vercel’s Privacy Notice and Hugging Face’s Privacy Policy.

The leaderboard reads public result rows from Supabase. Loading that page sends an ordinary network request to Supabase, which may process connection and request metadata for delivery, reliability, abuse prevention, and security. The browser can read separately labeled verified submissions and complete hosted runs under read-only policies; it cannot publish, edit, or delete results. See Supabase’s Privacy Policy.

The site loads typefaces from Google Fonts, so a visitor’s browser may make a request to Google. Links to GitHub, Vercel, and other external services are governed by those services’ own privacy notices. AMBIENT does not control their data practices.

Running the benchmark

You can run AMBIENT locally from GitHub or use the optional Hugging Face runner. A local run stays on infrastructure you choose except for requests sent to configured model providers.

The Space uses Hugging Face OAuth. Hugging Face always includes the standard openid profile sign-in scopes; the only additional scope requested is inference-api. Gradio injects a short-lived user token into the run callback; the application uses it only with https://router.huggingface.co/v1, holds it only in process memory for the active run, redacts it from captured errors, and excludes it from logs and evidence artifacts. The separate AMBIENT_SUPABASE_SECRET_KEY publishing credential is an operator-managed Hugging Face Space Secret and is never sent to visitors.

Run artifacts are held on the Space’s ephemeral storage for up to 30 minutes so you can download the bundle. Hugging Face, its configured Inference Providers, and Supabase process requests under their own policies. Inference usage is billed against the signed-in participant’s Hugging Face credits or account; review Hugging Face’s retention and billing terms before running the benchmark.

Community leaderboard submissions

Leaderboard bundles are submitted through the public GitHub repository, not through this website. A submitted bundle may include the contributor’s GitHub identity, system and model configuration, timestamps, manifests, transcripts, verdicts, and result summaries. Accepted bundles and repository review history are public. Contributors must remove credentials, private conversations, personal information, and material they do not have permission to publish before submission.

Retention and security

The maintainers do not operate a visitor-profile database or user-account system. Hosted-run artifacts expire from application storage after up to 30 minutes; OAuth tokens are not included in those artifacts. For a complete 400-question run, Supabase stores public result metadata including the memory name, pinned models, scores, control fingerprint, completion date, and evidence hash. Supabase also stores approved verified rows, and accepted evidence bundles remain in the public GitHub repository. Hosting, model, and linked service providers retain their own operational records according to their policies. No internet service can promise absolute security.

Your choices and contact

You may block third-party requests with browser controls, avoid external links, and download the repository directly from GitHub. For a privacy question, open an issue in the AMBIENT repository without including sensitive personal information; request a private contact channel if needed.

Changes

Material changes will be reflected on this page with an updated date. The repository history provides a public record of policy revisions once those changes are published.
