Account boundary

This website has no accounts and collects no API credentials. A submission is one .zip evidence bundle plus the frozen corpus SHA-256 attestation; nothing else is asked for.

Placement boundary

The certifier re-derives every published number from the raw artifacts in the bundle. A bundle that fails any check places nothing and returns the full list of failed checks. A certified bundle is stored as public evidence next to its row.
