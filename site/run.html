The GitHub repository is the complete benchmark and canonical protocol. The Hugging Face Space is the hosted runner. This website documents the method and publishes results.

What is being tested

The memory architecture—not model rank.

  1. 01

    The same reader answers the same questions in four controlled memory conditions.

  2. 02

    T4 bespoke-memory completion minus T1 no-memory completion is the architecture signal.

  3. 03

    A different judge requires a served-evidence trace before granting memory credit.

Account boundary

This website never receives a Hugging Face token. Beyond Hugging Face’s standard openid profile sign-in scopes, the Space requests only inference-api, and Gradio supplies the short-lived token directly to the run.

Cost and duration

Inference usage is billed against the signed-in participant’s Hugging Face credits or account. Each unique question can produce four reader answers and four judge calls, plus ingestion and checking work; start with the 10-question smoke.
